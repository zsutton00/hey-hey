When enrollment, approval, revocation, upgrade, or recovery fails, include the CLI version, protocol version, machine readiness state, non-secret reason code, and the affected operation. Do not paste machine credentials, private keys, passkey assertions, enrollment materials, canonical executable payloads, or protected-store contents. Recovery and authority-increasing changes must be performed on the exact local machine; support cannot restore local execution from an account or website session alone.
