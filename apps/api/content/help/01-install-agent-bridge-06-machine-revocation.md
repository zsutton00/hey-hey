Machine revocation is broader than controller revocation. Revoking a machine removes its ability to authenticate and receive host-affecting work, including work that a still-active controller might otherwise request. Revoking one controller leaves the machine and other active controllers in place. Choose the machine-level action only when the whole computer, its machine credential, or all authority on that computer must be stopped; choose controller revocation when one passkey credential must be removed.
