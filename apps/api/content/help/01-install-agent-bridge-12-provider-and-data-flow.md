The CLI runs agent sessions on your machine and sends the session traffic Hey Hey is designed to route or store to the platform. Prompts, task context, progress, and results can be sent to the user-selected model provider so that provider can produce the requested work; provider-specific session and cost metadata may return to Hey Hey. Controller credentials, machine private keys, WebAuthn assertions, and protected local secrets are not the payload of ordinary provider work. Review provider and platform settings before sending sensitive project content, and do not treat controller authorization as a promise that an agent or provider will make safe choices inside an approved turn.
